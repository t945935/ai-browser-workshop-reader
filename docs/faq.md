# 常見問題

## PowerShell 阻擋 npm.ps1

使用 npm.cmd，例如 npm.cmd ci，無須為此降低系統執行政策。

## 起始版無法啟動

start 是當章任務前的版本。第 2 章 start 尚無入口；第 16 章 start 的除錯測試故意失敗。先核對章節 README 與正文，再與 done 比較。

## 測試有 AI 回應，是否已連上 API？

背景 smoke 使用固定的離線回應，不能证明真實 API 成功。實際請求需金鑰、網路與服務額度；問題回報僅提供去除秘密的錯誤與操作順序。

## 重啟後資料不見

第 7 章書籍僅在記憶體，第 8 章保存設定而不保存書籍，第 9 章才加入 SQLite。不同章節及開發／安裝模式也可能使用不同 userData 路徑，先核對實際資料位置。

## 填入後為什麼沒有提交？

隨書功能先填入並讀回，由使用者核對後自行提交。提交次數是示範網頁的累積計數，不是每次填入都重置。

## Windows 阻擋執行

保存程式版本與錯誤，改用政策允許的測試環境或由管理者處理。不要停用政策作為通用解法。目前附件未取得完整乾淨安裝與更新驗收證據。

## 電子書頁碼不同如何回報？

提供章節、小節及短摘錄，另附閱讀器名稱；頁碼僅作輔助。
