# 《打造自己的專用瀏覽器，學會 AI 程式設計》讀者服務

用 Electron × GitHub，從需求、實作、除錯到發布。作者：Happy eBook Authors｜出版社：Happy eBook。

本儲存庫提供隨書附件、操作說明、常見問題及勘誤回報。目前書籍為校閱稿，尚未上架。附件版本為 `0.1.0-draft-results-review6`；不表示所有真實 API、Windows 安裝更新及人工操作已驗收。

## 下載與開始

- [章節附件 ZIP](downloads/chapters.zip)：第 1～18 章共 36 個 start／done 階段。
- [章節 Git 歷史 bundle](downloads/chapter-history.bundle)：可在本機 clone 並切換教學標籤。
- [下載檔案 SHA256](downloads/SHA256SUMS.txt)。
- [快速開始](docs/quick-start.md)、[章節對照](docs/chapters.md)、[常見問題](docs/faq.md)、[驗收範圍](docs/validation-status.md)。

請先解壓、選擇當章 start 並複製成自己的練習目錄。done 用於比較，不要覆寫原始附件。第 2 章 start 尚未有程式入口，第 16 章 start 的 CSV 測試刻意失敗。

## 勘誤與提問

書籍文字、程式或圖片錯誤請至 [Issues](https://github.com/t945935/ai-browser-workshop-reader/issues/new/choose)，選擇「書籍勘誤」或「操作問題」。提供章節／小節、附件版本、環境、重現步驟、預期及實際結果。EPUB 頁碼會隨閱讀器改變，請優先提供小節標題。

回報前先查看 [FAQ](docs/faq.md)、[勘誤表](docs/errata.md)及既有 Issues。截圖與錯誤訊息請去除 API 金鑰、個人資料及登入資訊。

## 附件與授權

此處提供隨書教學附件，完整 EPUB 不在本儲存庫公開。第三方套件依各自授權；書稿與圖片的公開重製授權尚未另行聲明，請勿推定可任意重製。附件中的練習資料為模擬資料。

GitHub Issues 為公開討論，沒有保證即時回覆時限。若後續啟用 Discussions 或發布新的附件版本，會在此更新入口。
